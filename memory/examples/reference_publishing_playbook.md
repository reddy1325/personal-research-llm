Operational playbook for long-form article publishing: outline conventions, citation style, image-handling rules, footnote vs inline reference policy, and a pre-publication checklist (voice rules check, fact verification, source-tier audit).

**How to apply:** Before any long-form article ships, re-check this playbook for any rules that apply to the current piece. Publishing conventions drift over time; the playbook is the source of truth for the current working procedure.
