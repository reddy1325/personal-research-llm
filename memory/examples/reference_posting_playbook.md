Operational playbook for posting to X covers: detection of reply-restricted parent posts, virtualized timeline workaround, search filter syntax (min_faves, lang, since/until), draft-clear vs posted state verification.

**How to apply:** Before any posting batch, re-check this playbook for any rules that apply to the current run. Posting platforms change behavior often; the playbook is the source of truth for the current working procedure.
